
**Unit Tests**

run the unit tests with the follow command

`npm run test:unit`

**Acceptance Tests**

The acceptance tests can be run at 2 different levels, either at the HTTP API level, or with Playwright through the website

These are the commands to run them

`npm run test:acceptance:api`
`npm run test:acceptance:web`

when running the test scope them to the specific file being worked on to reduce the amount of time they take, and simplify the output
